# GOV.UK Information Model
The GOV.UK Information Model contains the **canonical** information model for GOV.UK. It describes the information **conceptual** infrastructure for GOV.UK.

The Information Model consists of a set of [OWL](https://www.w3.org/OWL/) ontology text files (defined in [turtle](https://en.wikipedia.org/wiki/Turtle_(syntax))) that describe: 
- **Domain ontologies**. All the objects (classes and sub-classes) and the properties/attributes, for each domain. The domain describes the canonical objects for that domain. _E.g. Visa Domain_.
- **Content schemas**. All deployed content schemas, and content types, and their properties/attributes. The content schemas are used to define objects in Content Blocks and Content Types (i.e "content") only objects. _E.g. Tax Content Block_.
- **Taxonomies**. All Taxonomies used and all their taxons. The taxonomies exist in domains and content schemas but are collected in one place for ease of management. _E.g. Language Taxonomy_.

Other supporting files are stored in this repo. These provide documentation, model validation scripts, model export scripts, and other ad hoc files related to the management of the information model.

## Repo Structure ##
| File | Description |
|:------|:-----|
|`GOVUKOntology.ttl`| The root ontology (information model). The separate ontology files that comprise the overall ontology are imported into this file. |
|`Core.ttl`| All standard classes, data properties, object properties, annotation properties, and datatypes, that are used in all other ontology files. This ontology is imported into all other ontology files. |
|`Domain/<DomainName>.ttl`|The separate domain ontologies, one ontology file per domain. Each domain ontology file is included in the root ontology file.|
|`Taxonomy/<TaxonomyName>.ttl`|The separate taxonomy ontologies, one ontology file per taxonomy. Each taxonomy ontology file is included in the core ontology file. |
|`ContentSchema/<ContentSchemaName>.ttl`|The separate content schemas ontologies, one ontology file per content schemas. Each content schemas ontology file is included in the root ontology file. |
| `SHACL/*.ttl`|The [SHACL](https://www.w3.org/TR/shacl/) validation files that may be applied to any ontology file.|
|`XSLT/*.xslt`|The [XSLT](https://en.wikipedia.org/wiki/XSLT) files used for ontology validation and information model exports.|
| `RDF/*.rdf`| RDF (XML) equivalents of all .ttl files. Theses files are generated by a GitHub Action. This allows XSLT processing of the files. |
| `Tools`| Executables used by GitHub Actions in this repo. |
| `Outputs`| All output files produced by a GitHub Actions.|
